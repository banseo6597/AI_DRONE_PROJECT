# 욘두 — 음성 인식 AI 드론 제어 시스템

호출어 **"욘두"** 와 한국어 음성 명령으로 드론을 조종하는 프로젝트입니다.
오프라인 음성 인식(Vosk)으로 명령을 알아듣고, 아두이노 조종기가 BLE로 시판 드론에
제어 패킷을 보냅니다. 조이스틱 수동 조작과 음성 제어를 함께 쓰는 **하이브리드 제어**가 특징입니다.

> ⚠️ 이 README는 저장소에 실제로 올라온 코드(`main`, `drone`)를 기준으로 작성되었습니다.

---

## 🧩 시스템 구성

```
 ┌──────────────┐   USB 시리얼(9600bps)   ┌──────────────────┐   BLE   ┌────────────┐
 │  마이크       │   1바이트 명령(F/B/U/G)  │  아두이노 조종기   │ ─────▶ │ 시판 드론   │
 │   │          │ ──────────────────────▶ │   (drone.ino)     │  패킷   │   기체      │
 │   ▼          │                         │  + 조이스틱/버튼   │         │            │
 │ 라즈베리파이/PC│                         └──────────────────┘         └────────────┘
 │  (main.py)    │
 │  Vosk STT     │
 └──────────────┘
```

| 구성요소 | 파일 | 역할 |
|---------|------|------|
| 음성 통제소 | `main` (→ `main.py` 권장) | 마이크 입력 → Vosk로 한국어 인식 → 명령(F/B/U/G)을 시리얼로 송신 |
| 아두이노 조종기 | `drone` (→ `drone.ino` 권장) | 시리얼로 음성 명령 수신 + 조이스틱/버튼 수동 입력 → BLE로 드론에 패킷 전송 |
| 드론 기체 | (시판 제품) | BLE로 패킷을 받아 비행. 모델: **펌테크 아두이노 드론 2호 키트** |

> 📌 현재 두 소스 파일은 확장자가 없습니다. 깃헙 문법 강조와 아두이노 IDE 인식을 위해
> `main` → `main.py`, `drone` → `drone.ino` 로 이름을 바꾸는 것을 권장합니다.

## ⚙️ 동작 원리

### 음성 명령 흐름
1. 마이크 → `arecord`로 16kHz 모노 오디오 캡처
2. Vosk(오프라인 한국어 모델)로 실시간 음성 인식
3. 문장에 **호출어 "욘두"** 가 있고 명령어가 포함되면 해당 1바이트 코드를 시리얼로 전송
4. 아두이노가 명령을 받으면 `ACK:x` 로 수신 확인 응답

### 하이브리드 제어 (수동 우선)
아두이노는 매 루프에서 조이스틱과 음성 명령을 함께 보고 권한을 중재합니다.
- **조이스틱을 움직이면** → 즉시 수동 조작이 우선, 음성 명령(기억값) 초기화
- **조이스틱이 중립이면** → 음성 명령값을 드론에 반영
- 음성 명령은 한 번만 들어오므로, 수신 후 `CMD_HOLD_MS`(기본 800ms) 동안 값을 유지

## 🔌 하드웨어 연결

아래 핀 배치는 `drone` 코드 기준입니다. **실제 배선과 일치하는지 반드시 확인하세요.**

### 아두이노 조종기

| 연결 대상 | 아두이노 핀 | 비고 |
|----------|-----------|------|
| BLE 모듈 RX | A0 | `SoftwareSerial(A0, A1)` RX |
| BLE 모듈 TX | A1 | SoftwareSerial TX |
| 조이스틱 X (Roll) | A4 | `analogRead(4)` |
| 조이스틱 Y (Pitch) | A5 | `analogRead(5)` |
| 스로틀 ▲ 버튼 | D5 | 누르면 상승 (INPUT_PULLUP) |
| 스로틀 ▼ 버튼 | D6 | 누르면 하강 |
| Yaw ◀ 버튼 | D7 | 좌회전 |
| Yaw ▶ 버튼 | D8 | 우회전 |
| 시동/비상 버튼 | D9 | 시동(arm) + 비상정지 겸용 |
| 라즈베리파이 | USB | 시리얼 9600bps |

> 버튼은 모두 내부 풀업(INPUT_PULLUP)을 사용하므로, 한쪽은 GND에 연결합니다.

### 통신 패킷 (BLE)
조종기는 `at+writeh000d...` AT 명령으로 14바이트 payload를 드론에 전송합니다.
payload 구성: `roll, pitch, yaw, throttle, option, p_vel, y_vel` (각 2바이트, 리틀엔디안) + 체크섬.

## 💻 소프트웨어 설치

### 1) 라즈베리파이 / PC (음성 통제소)

> `arecord`를 사용하므로 **리눅스(라즈베리파이 OS 등) 환경**이 필요합니다.

```bash
# 오디오 도구 (arecord)
sudo apt update
sudo apt install -y alsa-utils python3-pip

# 파이썬 패키지
pip install vosk pyserial
```

### 2) Vosk 한국어 모델 다운로드

`main` 코드는 스크립트와 **같은 위치의 `model` 폴더**에서 모델을 읽습니다.

```bash
wget https://alphacephei.com/vosk/models/vosk-model-small-ko-0.22.zip
unzip vosk-model-small-ko-0.22.zip
mv vosk-model-small-ko-0.22 model    # 폴더 이름을 반드시 'model' 로
```

최종 구조:
```
프로젝트폴더/
├── main          # (→ main.py 권장)
└── model/        # Vosk 한국어 모델
    ├── am/
    ├── conf/
    └── ...
```

### 3) 마이크 장치 확인

```bash
arecord -l        # 카드/장치 번호 확인
```
`main` 코드의 `MIC_DEVICE = "plughw:0,0"` 값을 실제 카드 번호에 맞게 수정하세요.

### 4) 아두이노 조종기

- Arduino IDE에서 `drone`(→ `drone.ino`)을 엽니다.
- 추가 라이브러리 설치 불필요 (`SoftwareSerial`은 기본 포함).
- 보드에 업로드합니다. 시리얼 속도는 **9600bps**.

## ▶️ 실행 방법

```bash
# 1. 아두이노 조종기를 라즈베리파이/PC에 USB로 연결
# 2. BLE 모듈과 드론 전원 ON, 페어링 상태 확인
# 3. 음성 통제소 실행
python3 main          # (이름 변경 시 python3 main.py)
```

실행하면 아두이노 자동 탐지 → Vosk 모델 로드 → 마이크 스트리밍이 시작됩니다.

**사용 예:** 마이크에 대고 `"욘두 전진"`, `"욘두 상승"`, `"욘두 착륙"` 처럼 말합니다.
종료는 `Ctrl + C`.

## 🎙️ 음성 명령어

모든 명령은 호출어 **"욘두"** 와 함께 말해야 인식됩니다.

| 명령 | 전송 코드 | 예시 발화 | 드론 동작 |
|------|----------|----------|----------|
| 전진 | `F` | "욘두 전진" / "앞으로" | pitch 전진 |
| 후진 | `B` | "욘두 후진" / "뒤로" | pitch 후진 |
| 상승 | `U` | "욘두 상승" / "올라가" | throttle 증가 |
| 착륙 | `G` | "욘두 착륙" / "내려" | throttle 감소 |

- **중복 명령 방지:** 같은 명령은 `1.5초`(COMMAND_COOLDOWN) 안에 다시 보내지 않습니다.
- **응답 확인:** 아두이노가 `ACK:F` 형태로 수신을 알려주면 통제소에 ✅로 표시됩니다.

> 좌/우 이동, 정지, LED 등은 현재 음성 명령으로 구현되어 있지 않습니다(아래 한계 참고).

## 🛡️ 안전 주의사항

- **수동 우선:** 조이스틱을 건드리면 음성 명령은 즉시 무시되고 수동 조작이 우선합니다.
- **시동/비상(D9):** 비행 시작 전 D9로 시동(arm)하며, 비상 시 같은 버튼으로 정지합니다.
- **통신 두절 주의:** 현재 코드는 통신이 끊겨도 고도(throttle)를 유지합니다.
  음성/USB가 끊기면 드론이 계속 떠 있을 수 있으니, **반드시 D9 비상 버튼을 즉시 사용**하세요.
- 최초 테스트는 프로펠러를 떼거나 보호망이 있는 **실내 저고도**에서 진행하세요.

## 🧪 트러블슈팅

| 증상 | 원인 | 해결 |
|------|------|------|
| `No module named 'vosk'` | 패키지 미설치 | `pip install vosk pyserial` |
| `모델 로드 실패` | `model` 폴더 위치/이름 오류 | 모델 폴더명을 정확히 `model`로, 스크립트와 같은 위치에 |
| `아두이노 연결 실패` | 포트 미인식 | USB 재연결, `arecord -l`/`ls /dev/tty*`로 포트 확인 |
| 마이크 인식 안 됨 | `MIC_DEVICE` 불일치 | `arecord -l` 결과에 맞게 `plughw:카드,장치` 수정 |
| 인식은 되는데 드론 무반응 | BLE 페어링/패킷 문제 | BLE 연결 상태와 드론 모델별 패킷 포맷 확인 |
| 음성 오인식 잦음 | 모터 소음/먼 거리 | 마이크를 입 가까이, 조용한 환경에서 |
| 이륙 시 한쪽으로 쏠림(드리프트) | 모터/무게중심/프로펠러 편차 | `drone`의 `rollTrim`/`pitchTrim` 값 조절 (아래 참고) |

### 이륙 드리프트(편류) 보정
펌테크 드론은 이륙 시 기체 편차로 한쪽으로 쏠릴 수 있습니다. `drone` 펌웨어 상단의
트림 값으로 보정하세요. 수동 조작 중이 아닐 때(호버/AI 비행)만 적용됩니다.

```cpp
int rollTrim  = -20;  // 좌(-) / 우(+)
int pitchTrim = -20;  // 뒤(-) / 앞(+)
```

- **우측-앞**으로 쏠림 → 위 기본값처럼 `rollTrim` 음수(좌) + `pitchTrim` 음수(뒤)
- 보정이 과하면 값을 0에 가깝게, 부족하면 더 크게(±40 이내) 조절
- 방향이 반대로 작동하면 부호를 뒤집으세요
- 먼저 프로펠러 장착 방향·파손, 무게중심도 함께 점검하세요

## 📋 알려진 한계 / 개선 예정

- **음성 최종 인식 경로 점검 필요:** `main`에서 `SetMaxAlternatives(3)` 사용 시
  `Result()`의 JSON에 `text` 키가 없어, 현재 부분 인식(partial) 위주로 동작합니다.
- **통신 두절 시 자동 하강(failsafe) 미구현** — 안전상 추가 권장.
- **좌/우 이동·정지·LED 음성 명령 미구현** (코드상 F/B/U/G만 지원).
- **착륙이 점진적이지 않음** — "착륙" 1회당 throttle을 조금만 낮춰, 반복 발화가 필요.
- 플랫폼 의존: 음성 통제소는 `arecord` 기반이라 **리눅스 전용**.
